### How it was run

- **Signed in:** the desktop app's built-in browser, as `test-3570@privy.io`. That pane was hidden for the whole run.
  A hidden page gets no animation frames and no `ResizeObserver` callbacks. So a test-only shim drove
  `requestAnimationFrame` from a timer, and anything sized by `onLayout` (the agents grid) could not be measured
  there. It rendered in the first pass, before the pane was hidden.
- **Signed out:** a real headless Chromium (Playwright 1.63, Chrome for Testing build 1243). It also covered the
  visual items and a live window resize.
- **Claude in Chrome** connected partway through and was used for C1/C2. Its window was covered by other windows,
  so it was hidden too. Its network panel listed `HEAD` requests as 503 that the page itself saw as 200, so status
  codes were taken from the page's Performance API.
- **Console/network:** errors were read per tab; failed requests come from `performance.getEntriesByType('resource')`
  (signed in) and Playwright's response/requestfailed events (signed out).

### What was fixed

1. **Receipts CSV was empty beside 10 signed trades.** It read strategy runs only. It now also takes the audit
   trail's signed Bought/Sold rows (agent entries, the owner's buys and sales, closes) and skips any signature a run
   already accounts for (`server/src/audit/fills.ts`, tests). Owner trades now record units, price and the
   `jupiter-route` venue in their payload.
2. **Audit trail CSV wrote `Fri Sep 25 2026 … (Coordinated Universal Time)`.** It now writes ISO instants
   (`server/src/audit/log.ts`).
3. **The chat panel was boxed into the centred column on panel pages.** It is now the shell's root overlay
   (`app/_layout.tsx`, `DesktopShell`).
4. **The sign-in panel's email field slid under "Email me a code" and off the bottom.** That section now scrolls
   (`app/(onboarding)/wallet.tsx`). This also helps short phones.
5. **The split screen's 900pt glow made the document scrollable; a focus showed white below the app.** It is
   clipped, and html/body are painted the app's black.
6. **Signed out, a desk rendered its wide desktop layout squeezed into the 520pt panel.** `useDesktop()` now answers
   false inside the panel (`PanelScope`).
7. **Two aborted requests on every page load.** Privy's default wallet list built Coinbase/Base EVM SDKs, whose
   opener-policy check sent a HEAD for the page. The list is now Solana wallets only.
8. **Two server unit tests timed out intermittently.** `xstocks-route.test.ts` and `feeds.test.ts` re-import a whole
   route graph per test; a cold import from the external drive alone passed the 5s default. They now allow 30s.
9. **Earlier in the run:** `/rpc` CORS now allows the `solana-client` header; the ticket blocks a buy with no USDC
   and a sale of nothing held; the top-bar icons have labels; return-funds passes the copy audit.

- **Pyth:** its sponsored on-chain equity feeds are days stale and Hermes answers 401 without a key. Health says
  `degraded`, and prices fall back to the issuer's mark.
