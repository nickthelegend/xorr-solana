## P - PRE-IPO PARITY (second pass, 2026-09-22)

O12-O15 established that a T-Token could be granted, bought and closed on chain. This section
asks the next question — whether the rest of the app can SEE one — and the answer was no, in
eight separate places. Each was found by re-running the plan against a wallet that actually held
one, and each is re-verified below against the hosted build.

The shape is always the same: a list that means "everything this app can trade" was written as
`XSTOCKS` before a second asset class existed. `tradableTokens()` is the one list that answers it.

NOT CHANGED, and deliberately — flagged for a decision rather than fixed:

  The autonomous scanner's universe is still `XSTOCKS`, so an agent will not open a pre-IPO
  position on its own (a user or a strategy still can). This is not the same bug as the eight
  above. The scanner guards every candidate against a reference price and market hours, and a
  private company has neither: there is no Pyth feed for it, and Tessera's issuer mark sits about
  17% below the pool price it would actually fill at ($812.79 against $978.43 on 2026-09-22). An
  off-hours-style guard fed those two numbers refuses every sweep. Widening the universe without
  first deciding what guards a 24/7 private-company token would either disable that protection
  for the class or produce an agent that explains a refusal on every tick.
